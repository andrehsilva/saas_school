Como preencher a planilha de usuários

  • usuario: Nome de usuário único (ex: aluno1, prof_joao)
  • email: E-mail válido do usuário
  • nome: Primeiro nome
  • sobrenome: Sobrenome
  • senha: Senha inicial do usuário
  • papel: aluno, professor, coordenador, diretor, colaborador ou responsavel
  • serie: (Para coordenador/diretor/colaborador) Nome da série (ex: 1º Ano)
  • classe: (Para aluno/professor) Nome da(s) turma(s) (ex: 1A;2B)
  • filhos: (Para responsável) E-mails dos filhos separados por ponto e vírgula

Dica: Baixe a planilha modelo para garantir o formato correto.
